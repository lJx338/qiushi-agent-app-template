# 本地模拟与真实环境对照 v1.0

适用 `@qiushi/app-kit 0.4.0-dev.2`。报告验证时必须写明下表中的级别；不要把较低级别的通过称为真实接入或生产验收。

| 维度 | 本地模拟已可做 | 需要真实平台/环境的证据 | 当前结论 |
| --- | --- | --- | --- |
| 身份与租户 | `DevelopmentExecutor` 的合成 actor、tenant、安装、停用和权限拒绝 | 独立 customer 登录会话、成员/安装/字段/用途重检、撤权传播 | 未由本地模拟证明 |
| 业务数据 | 合成 Customer/Draft、schema、确定性领域规则和内存幂等 | PostgreSQL/RLS、持久 CAS、审计、备份/恢复和真实隔离 | 未由本地模拟证明 |
| 外部数据源 | 合成 provider 结果、拒绝、撤权与陈旧状态分支 | 已批准 binding、真实源身份、字段映射、429/403、撤权后缓存失效 | 未由本地模拟证明 |
| UI 与运行时 | `qiushi.ui.v1` 声明、本地预览、action/data/conversation bridge 契约 | 客户宿主装配、真实 Edge loader、资源隔离和插件策略 | 未由本地模拟证明 |
| 制品交付 | `.tgz`、`.release.json`、SHA-256、门户元数据校验和构建回执 | 可信构建签名、制品库、上架、租户开通和生产部署 | 未由本地模拟证明 |

## 可以怎样写验证结论

可写：`开发模拟通过：tenant-a 可创建合成草稿；no-permission 与 disabled 被 DevelopmentExecutor 拒绝；app:pack 输出摘要一致的 development descriptor。`

不可写：`已完成客户权限`、`已接入飞书`、`已生产发布`、`已完成真实 Edge 隔离`，除非对应真实平台任务提供了环境、版本、非敏感测试身份、执行时间、步骤和结果证据。

## 开发预览的边界

`npm run app:dev` 提供短生命周期本机 HTTP 预览。它要求开发 token 与同源 Origin，且可演练合成成功、无权、停用和错误输入；重启后数据清空。它不是客户前台、不是平台 BFF、不会保留审批/队列、不会连接客户源，也不证明浏览器 Cookie/Edge loader/租户隔离。

## 真实环境准备清单

当平台负责人宣布某项真实能力可验收时，先取得：目标版本/环境、测试租户与测试身份、授权/撤权步骤、允许的数据和字段、预期成功/拒绝/未知结果、审计或回执位置，以及恢复或清理方案。真实凭证只在平台受控配置中使用，绝不贴进应用仓库、fixture、Workpad 或提交日志。

真实验证失败时记录实际命令/请求、时间、环境版本、最短脱敏错误和预期/实际差异；不要用开发 fixture 覆盖失败，也不要在应用内回退到高权限机器人身份。
